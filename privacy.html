Privacy Policy

Effective date: October 11, 2026

This policy describes the M&A Discovery informational website and the current development-stage product. The website is hosted on GitHub Pages. It is not an account login service.

Information handled

This static website does not include registration forms, analytics scripts, advertising trackers, or a database that collects visitor-submitted information. GitHub, as the hosting provider, may process technical request data under its own policies.

The M&A Discovery development app processes product search terms, public listing information, and manual supplier notes to provide research and draft preparation. Some application data is held within a local browser session; handling may change as the software develops.

TikTok integration

TikTok Login Kit is not yet connected to the released application. If implemented, TikTok sign-in will require explicit authorization. The app will request only permissions necessary for the functionality offered, explain the data used, and provide a means to disconnect the account. TikTok publishing will not occur without a separate user approval step.

Data sharing and external links

When users open eBay or supplier websites, those services may collect information according to their own privacy policies. The informational website does not sell personal information.

Retention and requests

At this development stage, the static website does not maintain a visitor account database. For questions, corrections, or data-related requests, use the project's GitHub issue tracker; do not include sensitive personal information or credentials in public issues. A dedicated private contact channel will be added before a public account integration launches.

Updates

This policy will be updated before any public TikTok integration or material change in data processing.
